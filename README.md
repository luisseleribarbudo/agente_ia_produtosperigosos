# 🚚 Agente IA para Transporte de Produtos Perigosos

Projeto desenvolvido como trabalho final do curso **Criação de Agentes com Microsoft Foundry**.

## 📋 Sobre o Projeto

O **Agente IA para Transporte de Produtos Perigosos** é uma aplicação baseada em Inteligência Artificial que auxilia usuários na consulta de informações relacionadas ao transporte de produtos e resíduos perigosos.

O agente utiliza como base de conhecimento a documentação técnica e a regulamentação vigente, fornecendo orientações sobre requisitos legais, documentação obrigatória, classificação dos produtos, acondicionamento, sinalização e demais condições necessárias para um transporte seguro e em conformidade com a legislação.

---

## 🎯 Objetivo

Disponibilizar um assistente inteligente capaz de responder dúvidas sobre o transporte de produtos perigosos de forma rápida, precisa e fundamentada na documentação fornecida, auxiliando profissionais da área logística e ambiental na tomada de decisões.

## ✨ Funcionalidades

- Consulta por nome do produto ou resíduo perigoso.
- Respostas baseadas na documentação técnica anexada ao agente.
- Orientações sobre:
  - Classificação do produto;
  - Regras para transporte;
  - Documentação obrigatória;
  - Embalagem e acondicionamento;
  - Sinalização e identificação;
  - Restrições e cuidados durante o transporte.
- Respostas fundamentadas na legislação e normas utilizadas como base de conhecimento.

## 🚀 Como Utilizar

1. Acesse a aplicação publicada.
2. Digite o nome do produto ou resíduo perigoso que deseja consultar.
3. Faça sua pergunta ao agente.
4. O sistema retornará as orientações com base na documentação técnica utilizada como fonte de conhecimento.

### Exemplos de perguntas

- Como transportar Ácido Sulfúrico?
- Quais documentos são necessários para transportar resíduos perigosos?
- Quais são as regras para transporte de Tinta Inflamável?
- Como deve ser feita a sinalização do veículo?
- Quais EPIs são recomendados para este produto?

## 📚 Base de Conhecimento

O agente foi desenvolvido utilizando documentação técnica referente ao transporte de produtos e resíduos perigosos, incluindo normas, legislações e manuais aplicáveis.
